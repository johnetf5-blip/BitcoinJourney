BITCOIN JOURNEY · LESSON 4

How Does Bitcoin Mining Work?

Bitcoin mining is the process that helps confirm transactions, add new blocks to the blockchain and secure the Bitcoin network. It uses specialised computers to compete in a mathematical guessing process called Proof of Work.

1. What are Bitcoin miners?

Miners are people or organisations that run specialised computers to participate in the Bitcoin network.

They collect valid, unconfirmed transactions and organise them into candidate blocks. They then compete to find a valid Proof of Work for a block.

2. What is Proof of Work?

Proof of Work is a system in which miners repeatedly calculate hashes using the block header and a changing value called a nonce.

They are searching for a hash that meets the network's difficulty target. There is no shortcut that reliably predicts the answer: miners must perform many attempts.

Finding a valid result is difficult, but checking that result is easy for other network participants.

Simple example

Imagine trying different numbers until a computer produces a hash that meets a particular rule. Every attempt costs computing work. The first miner to find a valid result can propose the next block.

3. What happens when a miner finds a block?

  1. The miner broadcasts the proposed block to the network.
  2. Other nodes check the block and its transactions.
  3. If it follows the consensus rules, nodes can accept it.
  4. Miners continue building on the accepted chain.

Miners do not get to decide the Bitcoin rules by themselves. Full nodes independently check whether blocks and transactions follow those rules.

4. Why does Bitcoin mining use electricity?

Mining computers perform enormous numbers of calculations. These calculations require electricity and specialised hardware.

The energy expenditure makes it costly to produce blocks and helps make attacks on the network expensive.

Mining hardware is often called an ASIC. These machines are designed specifically to calculate Bitcoin hashes efficiently.

5. How do miners earn Bitcoin?

A miner who successfully creates an accepted block can claim the block reward. This consists of two parts:

  • Block subsidy: Newly issued bitcoin, according to the protocol's schedule.
  • Transaction fees: Fees from transactions included in that block.

The block subsidy is reduced by half every 210,000 blocks. This event is called the halving.

Transaction fees are paid by users and are not newly created bitcoin.

6. Mining and the 21 million limit

Mining does not allow miners to create unlimited bitcoin. Full nodes check that every block follows Bitcoin's consensus rules, including the permitted block subsidy.

A miner cannot make an invalid block valid simply by finding a Proof of Work. Nodes can reject blocks that break the rules.
