BITCOIN JOURNEY · LESSON 5

What Are Bitcoin Nodes?

Bitcoin nodes are computers that participate in the Bitcoin network. They independently check transactions and blocks against Bitcoin's consensus rules.

1. What is a Bitcoin node?

A Bitcoin node is software running on a computer that communicates with other computers in the Bitcoin network.

A full node downloads and verifies blocks and transactions. It checks whether they follow the rules of Bitcoin.

A full node does not need permission from a bank, miner or exchange to perform these checks.

2. What does a node actually do?

  • Receives transactions from the network.
  • Checks whether transactions are valid.
  • Receives new blocks.
  • Checks the transactions inside each block.
  • Checks that the block follows consensus rules.
  • Shares valid information with other connected nodes.

A full node independently verifies the rules rather than simply accepting a miner's claim that a block is valid.

3. Miners versus nodes

Miners and nodes have different responsibilities. They work together, but they are not the same thing.

Miners

Use computing power to perform Proof of Work and propose new blocks.

Full nodes

Independently check blocks and transactions against the Bitcoin consensus rules.

A miner can propose a block, but full nodes can reject it if it breaks the rules.

4. How do nodes protect the 21 million limit?

Bitcoin's consensus rules determine how many new bitcoins can be issued in each block.

Full nodes check that miners do not claim more block subsidy than the rules allow.

If a miner creates a block that violates the permitted subsidy, a validating node rejects that block.

Important idea

Mining does not give miners permission to change Bitcoin's monetary rules. Full nodes independently verify the blocks they receive.

5. What does "verify, don't trust" mean?

The idea is simple: instead of depending entirely on someone else's word, use your own software to check the information.

For example, an exchange might tell you that a Bitcoin transaction has been confirmed. With your own full node, you can independently check the blockchain.

Running a node gives you more independent verification. It does not guarantee that every wallet or computer connected to it is secure.

6. Can you run your own Bitcoin node?

Yes. Anyone with suitable computer hardware, storage and an internet connection can run Bitcoin node software.

Examples of node software include:

  • Bitcoin Core
  • Bitcoin Knots

A node needs time and storage to download and verify blockchain data. You can also configure a pruned node to use less storage.

Running a node does not automatically earn you Bitcoin. It is mainly about independently verifying the network.
